# APK v2.3 Ready!

The new APK with the **Database Dump Download** feature is ready.

## Features
- **Database Dump**: You can now download a full SQL backup of your database directly to your device.
- **Native Download**: The file is saved to your **Downloads** folder (or Documents if Downloads fails).
- **UI Fixes**: The "Database Storage" card is now visible on all dashboards and removed from "More" screens.

## File Location
The APK file is located at:
`rks_v2_3.apk`

## Installation
1. Transfer the file to your Android device.
2. Tap to install.
3. If prompted, allow installation from unknown sources.

## Testing
1. Open the app.
2. Go to any Dashboard (HomeSnacks, Farm, or Home Personal).
3. Scroll down to the **Database Storage** card.
4. Click **Dump DB**.
5. Confirm the dialog.
6. Check your **Downloads** folder for the `.sql` file.
